## 完整打包

在仓库根目录执行 `python latest/build_package.py`，输出 `dist/辞书综述_完整材料包_20261008.zip`。

当前包共10个文件：本说明、润色原稿、插图MD、HTML、PDF、五张PNG。打包脚本和VERSION_STATUS.md保存在仓库，不在现有ZIP内。当前参考文献直接查看润色稿末尾的42项文献，当前大纲直接查看同稿章节标题，不借用旧28项或35项编号。

脚本检查必需文件是否齐全以及ZIP完整性。本轮另已人工运行文件级核对，确认正文、PDF提取文字和PNG与交付材料的对应；不能把这些一次性核对描述为现有脚本已经具备的全部自动校验功能。

GitHub Actions会在本目录更新时自动运行。下载成功运行中的 `current-review-bundle` 工件，解开外层ZIP后即可取得完整材料包；工件按现有设置保留30天，过期后可重新运行工作流或脚本。
