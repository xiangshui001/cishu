## 正文与插图的边界

远端润色稿与作者上传稿的正文、表格和文献相同；只省略文件末尾的一个换行字符。插图MD只增加五行图片引用及排版空行。PDF为24页，文字提取内容与对话交付版逐页一致；为控制体积压缩了内嵌图像，完整PNG单独保留。

五图均为概念示意，不是原论文实验图或辞书引文。**图2中的具体词例、关系示例和辞书版次尚未逐条核验，不宜作为已核实的引用证据。** 图示简化不能替代正文的知识对象、方法边界与证据限定。

本仓库不收录商业辞书全文数据库或受限论文附件。正式论文、预印本及社区资料的身份与核读深度以对应版本的正文和记录为准；版本整理与文件一致性检查不等同于新增学术验证。
