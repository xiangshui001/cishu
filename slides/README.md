## 使用方式

正文23页、参考文献附录4页，共27页，16:9。正文建议约17—20分钟；参考附录不计固定讲述时间。图示和表格为可编辑PowerPoint图形，不是整页截图。

采用深青与浅色学术排版。主要中文字体为Noto Sans CJK SC，封面使用Noto Serif CJK SC；不附带字体文件。机器缺少字体时优先使用PDF，或安装合法来源字体后再打开PPT检查换行。

没有虚构汇报者、学号或导师。需要时在封面自行添加。课程提交前仍需按学校规则完成核读、修改和AI辅助说明。

## 重建

环境：Python 3.10及以上、`python-pptx==1.0.2`。PDF导出另需LibreOffice及上述CJK字体。

```bash
python -m pip install python-pptx==1.0.2
python scripts/build_presentation.py
# 安装LibreOffice后：
python scripts/build_presentation.py --pdf
```

生成器只读 `03_draft.md` 的参考文献及 `slides/presentation.json` 的审阅后内容；不会覆盖初稿或其他文本材料。若初稿发生变化，需先人工核对页面内容，再更新presentation.json内记录的来源SHA256，避免悄悄把旧PPT当作新版初稿的对应版本。

GitHub Actions用于从内容源重建并提交PPT、PDF、讲稿及清单，写入路径固定在slides目录下。不使用付费模型，不读取外部账号信息，不修改仓库可见性。推送若遇并发更新则正常失败，不强制覆盖。
